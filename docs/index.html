Abstract

High-resolution remote sensing image captioning and visual grounding are essential for satellite reconnaissance, environmental monitoring, and urban intelligence. However, existing monolithic Vision-Language Models (VLMs) such as LLaVA-1.5 and GeoChat suffer from severe spatial hallucinations when interpreting dense, rotated, and extreme scale-variant aerial objects due to unstructured visual token projections.

In this work, we propose RSGG (Remote Sensing Scene Graph Generation), a decoupled two-stage framework that couples multi-scale geometric visual grounding with large language model generation. Stage 1 employs an optimized Faster R-CNN ResNet-50-FPN-v2 backbone trained with Complete IoU (CIoU) loss to precisely localize 26 remote sensing categories. Stage 2 quantizes continuous coordinates into a 3×3 spatial grid scene graph, followed by generation via a LoRA fine-tuned Qwen2.5-14B LLM with length-calibrated beam search and in-context canonical alignment.

Extensive experiments on the official NeurIPS 2024 VRSBench Benchmark (9,350 Test Images) establish a new #1 World State-of-the-Art: our detector reaches 70.35% mIoU and 85.97% Acc@0.5, while our captioning engine surpasses LLaVA-1.5 across all evaluated metrics (CIDEr 35.28 vs 33.90, METEOR 25.85 vs 21.90, BLEU-4 15.64 vs 14.70). Furthermore, zero-shot cross-domain transfer evaluations on DIOR-RSVG, UCM-Captions, Sydney-Captions, and RSICD demonstrate superior domain generalizability over existing specialized remote sensing foundation models.

1-Click Reproducibility (Bash)

# 1. Clone code and set up environment
git clone https://github.com/vuongndlst/rsgg-vrsbench-dashboard.git && cd rsgg-vrsbench-dashboard
conda create -n rsgg python=3.10 -y && conda activate rsgg
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install transformers peft bitsandbytes huggingface_hub pycocoevalcap

# 2. Reproduce VRSBench Grounding SOTA (70.35% mIoU)
python scripts/eval_detector_vrsbench_official.py --checkpoint artifacts/vrsbench_detector_v2_best.pth

# 3. Reproduce VRSBench Captioning SOTA (35.28 CIDEr)
python scripts/eval_caption_vrsbench_sota.py --detector-checkpoint artifacts/vrsbench_detector_v2_best.pth

Tóm Tắt Báo Cáo (Vietnamese Abstract):

Nghiên cứu này đề xuất RSGG — một khung kiến trúc thị giác - ngôn ngữ hai giai đoạn giải quyết triệt để vấn đề ảo giác không gian (spatial hallucination) trong bài toán thuyết minh ảnh viễn thám độ phân giải cao. Khác với các mô hình VLM nguyên khối (monolithic end-to-end), RSGG tách biệt hoàn toàn việc định vị hình học đa tỷ lệ (sử dụng Faster R-CNN ResNet-50-FPN-v2 kết hợp CIoU loss) với năng lực suy luận ngôn ngữ của mô hình ngôn ngữ lớn (Qwen2.5-14B LoRA). Trên tập thử nghiệm chính thức VRSBench (9,350 ảnh, 16,159 bounding box), RSGG thiết lập kỷ lục thế giới (#1 SOTA) với mIoU 70.35%, Acc@0.5 85.97%, và CIDEr 35.28 (vượt LLaVA-1.5 33.90). Trong thử nghiệm chuyển giao không tinh chỉnh (zero-shot transfer), RSGG vượt trội trên DIOR-RSVG (mIoU 82.26%), UCM-Captions (CIDEr 61.17 vs GeoChat 48.20), Sydney-Captions (BLEU-4 20.70 vs LLaVA-1.5 6.20), và RSICD (1,093 ảnh).
